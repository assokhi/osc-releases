# osc

Keeps your documents safe in your own private Telegram group.

## Install (Windows 10/11)

1. Press Start, type **PowerShell**, open it.
2. Paste this line and press Enter:

   irm https://github.com/assokhi/osc-releases/releases/latest/download/install.ps1 | iex

3. osc opens by itself. Next time, type **osc** in the Start menu.

Running the same line again updates osc. To remove it, type `osc uninstall` in PowerShell.
